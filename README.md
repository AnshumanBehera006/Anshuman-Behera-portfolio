# Anshuman Behera — Professional Portfolio

A modern, responsive, and professional single-page portfolio website for **Anshuman Behera** (B.Tech 4th Year | Frontend & Web Developer).

Built with **React.js** and **pure custom CSS (CSS Variables, Flexbox, and CSS Grid)** — clean, uncluttered, and completely free of third-party CSS frameworks.

## 🛠️ Tech Stack & Design System

- **Framework:** React.js 19
- **Build Tool:** Vite
- **Styling:** Custom Vanilla CSS with CSS Variables
- **Design Aesthetic:** Professional dark palette with subtle slate blue accents (no loud/bold neon colors or unnecessary decorative icons).
- **Typography:** Plus Jakarta Sans & JetBrains Mono
